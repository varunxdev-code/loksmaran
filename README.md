# LokSmaran prototype

Simple heritage product: village archive + visitor trails.

```bash
cd sih-local-archives/web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

- **Visit** — public crafts, festivals, kitchens
- **Archive** — village + public memories, search
- **Record** — capture with required consent
- **Pricing** — Village free · Visitor ₹199 · Institution

Family recordings never appear on Visit. Seed media in `public/seed/` is fake.
